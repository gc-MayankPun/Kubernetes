## Basic Idea

Codebase + Dependencies + Runtime + OS is what makes a server and when we bring all these in one file then it is called Image.

And when we run this Image we get container.

Running the same Image again and again will get us multiple new containers.

## Why Kubernetes

It is used to automate the deployment, scaling and management of containerized applications, enabling high availability and efficient resource utilization.

And not only this...

We don't deploy an application just once. We continuously make changes, fix bugs, add features and release new versions.

Normally, shutting down Version 1 before starting Version 2 could cause downtime.

This is where Kubernetes helps us!
